## `query_contracts`

Ask a question about one or more contracts (clause lookup or general Q&A).

Runs the full agent: routing -> hybrid retrieval -> cross-encoder rerank -> draft ->
claim-level verification (with re-retrieval on failure) -> cited answer.
Leave contract_ids empty to let the router pick contracts from the question.

**Input**

| Field | Type | Required | Description |
|---|---|---|---|
| `question` | `string` | yes | Natural-language question about the contracts |
| `contract_ids` | `list[string] \| null` | no (default `None`) | Optional scope; empty lets the router choose |

**Output**

| Field | Type | Required | Description |
|---|---|---|---|
| `answer` | `string` | yes | Answer with inline [n] citation markers |
| `query_type` | `string` | yes |  |
| `citations` | `list[Citation]` | yes |  |
| `verification_verdict` | `string` | yes | pass \| pass_pruned \| fail \| insufficient |
| `supported_claims` | `integer` | yes |  |
| `total_claims` | `integer` | yes |  |
| `retries` | `integer` | yes |  |

<details><summary><code>Citation</code></summary>

| Field | Type | Required | Description |
|---|---|---|---|
| `n` | `integer` | yes |  |
| `contract_id` | `string` | yes |  |
| `contract_title` | `string` | yes |  |
| `section` | `string` | yes |  |
| `page_start` | `integer` | yes |  |
| `page_end` | `integer` | yes |  |
| `quote` | `string` | yes | Verbatim supporting text from the contract |

</details>

## `flag_risks`

Scan a contract for risky clauses (uncapped liability, auto-renewal, one-sided indemnity,
broad IP assignment, restrictive non-compete, change-of-control, minimum commitments, etc.).
Every flag quotes the source clause; flags whose quote cannot be found verbatim or that an
independent verifier rejects are dropped.

**Input**

| Field | Type | Required | Description |
|---|---|---|---|
| `contract_id` | `string` | yes | contract_id from list_contracts |
| `top_n` | `integer` | no (default `5`) | Maximum number of flags to return |

**Output**

| Field | Type | Required | Description |
|---|---|---|---|
| `contract_id` | `string` | yes |  |
| `contract_title` | `string` | yes |  |
| `flags` | `list[RiskFlag]` | yes |  |

## `ingest_contract`

Add a new contract PDF (absolute path on the server machine) to the index so it can be
queried and risk-scanned. Returns the new contract_id.

**Input**

| Field | Type | Required | Description |
|---|---|---|---|
| `pdf_path` | `string` | yes | Absolute path to a text-based PDF on the server machine |
| `title` | `string \| null` | no (default `None`) | Display title; defaults to the file name |
| `contract_type` | `string` | no (default `Unknown`) | e.g. Supply, License, Distributor |

**Output**

| Field | Type | Required | Description |
|---|---|---|---|
| `contract_id` | `string` | yes |  |
| `title` | `string` | yes |  |
| `contract_type` | `string` | yes |  |
| `n_pages` | `integer` | yes |  |
| `source` | `string` | yes |  |
